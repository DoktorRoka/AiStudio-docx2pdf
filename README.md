# Ai Studio Converter

Tampermonkey-скрипт, который автоматически конвертирует `.docx` в `.pdf` при загрузке в Google AI Studio и передаёт PDF обратно в механизм загрузки файлов — полностью локально, в браузере.

## Проблема

Интерфейс AI Studio не позволяет добавить `.docx` напрямую в чат.

## Решение

```text
DOCX → mammoth → HTML → html2canvas → canvas → jsPDF → PDF → DataTransfer → change → AI Studio
```

1. Перехват выбора файла (`change`, capture-фаза на `document`).
2. Перехват drag&drop (`drop`, capture-фаза на `document`).
3. Конвертация: mammoth (DOCX→HTML) → html2canvas (отрисовка с системными шрифтами, кириллица) → постраничная нарезка A4 → jsPDF (Blob application/pdf).
4. Инъекция PDF обратно через `DataTransfer` + синтетическое `change`-событие — AI Studio видит обычный PDF и прикрепляет его.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Установите скрипт:
   * Создайте новый скрипт → вставьте содержимое `ai-studio-docx2pdf.user.js` → `Ctrl+S`.
   * Или установите по [прямой ссылке](https://github.com/DoktorRoka/AiStudio-docx2pdf/raw/refs/heads/main/reference/ai-studio-docx2pdf.user.js)
3. Откройте `https://aistudio.google.com`, выберите `.docx` через кнопку загрузки или перетаскиванием — появится прикреплённый PDF с тем же именем.

## Возможности

- Текст, абзацы, заголовки, списки, таблицы, встроенные изображения, ссылки.
- Несколько `.docx` одновременно; не-docx файлы проходят без изменений.
- Работает и через кнопку загрузки, и через drag&drop.
- Библиотеки (mammoth 1.12.1, html2canvas 1.4.1, jsPDF 2.5.1) встроены в файл — CDN не требуется.
- Содержимое документов никуда не отправляется и не сохраняется на диск.

## Ограничения

- Точная вёрстка может отличаться от MS Word (компромисс браузерной конвертации).
- Текст в PDF растровый (страницы рисуются в canvas).
- Колонтитулы, сноски, поля страницы и сложные стили не поддерживаются в полном объёме.

## Диагностика

Подробные логи в консоли включаются установкой `DEBUG = true` в начале файла.
Текущий статус библиотек: `window.__AISD2P_DIAG__()` в консоли страницы. При старте скрипт также печатает итоговую диагностику (`Итоговая диагностика (...)`).
